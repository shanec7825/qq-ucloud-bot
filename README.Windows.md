# Windows 发行版快速说明

本地新版安装包为 `QQ-Agent-Setup-1.3.0-x64.exe`。安装完成后，从桌面或开始菜单打开 **QQ Agent**。

已有项目：点“选择已有项目”，选原项目根目录，继续使用其配置和授权。全新使用：先点“准备运行组件”，再点“启动机器人”和“QQ 登录”。需要扫码、验证码或设备验证时请自己完成。

服务就绪后直接进入 NapCat 原版 WebUI。窗口顶部保留“QQ 登录”“插件管理”和“运行管理”；需要另一个账号时，在运行管理中使用“切换 QQ 账号”。网页里的“退出 Web Login”不等于退出 QQ 账号。

关闭窗口会收起到托盘。双击托盘图标，或者再次点击桌面／开始菜单快捷方式，就能找回窗口。托盘“退出桌面程序”保留后台；停止 AI 后台请用顶部运行管理中的“停止机器人”。

设置入口：**插件管理 → 对应卡片齿轮**，直接使用 NapCat 原生配置面板，无 iframe 或内层侧栏。选择配置分类与记录，编辑后点击原生“保存”。换 QQ 不会清空模型、提示词、其他服务授权与历史报告；新 QQ 的群列表和报告接收人需确认。

默认工作区：`%LOCALAPPDATA%\QQAgent\workspace`。已有项目仍使用原目录。卸载应用保留工作区；再次安装后可重新选择。发行包不包含开发者账号或登录信息，也没有固定的通用管理密码。

需要 Windows 10/11 x64、.NET Framework 4.8 和 WebView2 Runtime。缺少 WebView2 时使用 [微软官方安装入口](https://developer.microsoft.com/microsoft-edge/webview2/)。便携版必须完整解压，不能单独移动 `QQAgent.exe`。

网页备用入口：`http://127.0.0.1:6099/webui/`。若服务未运行，先从桌面应用启动；失败日志位于工作区 `data/desktop-napcat.log` 和 `data/napcat-engine.log`，日志可能包含本机认证信息，请勿公开上传。

完整功能与构建说明见 [README.md](README.md)。
