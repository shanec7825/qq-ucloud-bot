# Qlyra Windows 发行版快速说明

当前版本为 2.6.1，安装包为 `Qlyra-Setup-2.6.1-x64.exe`，便携包为 `Qlyra-2.6.1-win-x64.zip`，整套插件包为 `Qlyra-Plugins-2.6.1-win-x64.zip`，本地构建位于 `release/2.6.1/`。以实际发行文件与校验清单为准；推送源码不会自动替换正在运行的应用。便携包完整解压后打开 **Qlyra.exe**；已有安装可从桌面或开始菜单打开 **Qlyra**。

2.6.1 包含首条完整文字提前发送、连续补充合并、旧回复尾部停止和语音等待打断。详见 [发行说明](docs/releases/v2.6.1.md)。

已有项目：点“选择已有项目”，选原项目根目录，继续使用其配置和授权。全新使用：启动页（启动向导）会先检查系统环境（Windows 10/11 x64、.NET Framework 4.8、WebView2、Node 运行时）并显示工作区与运行时组件状态，点“一键准备并启动”即可自动准备组件并拉起后台（也可分步“准备运行组件”→“启动机器人”，下载进度实时显示），就绪后打开“QQ 登录”。端口被其它工作区占用时，按工作区卡片提示点“关闭其它后台并继续”即可释放；“连接与端口”卡可查看本机监听并关闭多余端口。需要扫码、验证码或设备验证时请自己完成。

服务就绪后直接进入 NapCat 原版 WebUI。窗口只显示 NapCat 原版界面；启动、停止、组件准备和切换账号等操作集中在任务栏托盘图标的“运行管理”。网页里的“退出 Web Login”不等于退出 QQ 账号。

关闭窗口会收起到托盘。双击托盘图标，或者再次点击桌面／开始菜单快捷方式，就能找回窗口。托盘“退出桌面程序”保留后台；停止 AI 后台请用托盘“运行管理”中的“停止机器人”。

设置入口：**插件管理 → 对应卡片齿轮**提供原生简版设置；**扩展页面**提供 chat、语音、GitHub、云盘、ucloud、To Do 六个工作台。chat 按联系人选择普通或记忆模式，并分配角色；语音独立设置统一声音指令。ucloud 分为“待交作业”“站内通知”“连接与提醒”，可直接阅读作业与通知正文。

To Do 的即时通知按群纵向显示，点击单条通知加入待办；定时整理保存在本地，支持模板和简洁／详细输出。两者均不自动私聊推送 QQ，日历使用 Google Calendar 草稿或 ICS。模型、语音、工具和联系人规则由各登录 QQ 共用；各 QQ 连接仍需独立 OneBot / NapCat 实例，记忆按连接、角色和聊天对象隔离。完整工作流见 [工作台与业务边界](docs/PRODUCT-WORKSPACES.md)。

默认工作区：`%LOCALAPPDATA%\QQAgent\workspace`。已有项目仍使用原目录。卸载应用保留工作区；再次安装后可重新选择。发行包不包含开发者账号或登录信息，也没有固定的通用管理密码。

Qlyra 是原 QQ Agent 的新名称，沿用原安装身份、数据目录和授权。安装后创建 Qlyra 快捷方式；发行包仍保留 `QQAgent.exe` 兼容入口，已有固定快捷方式可继续使用。

需要 Windows 10/11 x64、.NET Framework 4.8 和 WebView2 Runtime。缺少 WebView2 时使用 [微软官方安装入口](https://developer.microsoft.com/microsoft-edge/webview2/)。便携版必须完整解压，不能单独移动 `Qlyra.exe`。

网页备用入口：`http://127.0.0.1:6099/webui/`。若服务未运行，先从桌面应用启动；失败日志位于工作区 `data/desktop-napcat.log` 和 `data/napcat-engine.log`，日志可能包含本机认证信息，请勿公开上传。

完整功能与构建说明见 [README.md](README.md)。
