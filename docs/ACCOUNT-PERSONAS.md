# QQ 账号与人格池

**Last Updated:** 2026-10-21 · 2.0.0 本地候选版
**Entry Points:** `src/settings.mjs`、`src/settings-migrations.mjs`、`src/runtime.mjs`、`src/managed-memory.mjs`

在 NapCat「插件管理 → 机器人核心 → 配置齿轮」中选择配置分类，编辑后点击 NapCat 原生「保存」。切换分类前先保存。

## 配置顺序

1. 在「人格池」新增人格，填写名称、人格设定和需要的模型设置。人格仍保存在 `profiles`，旧方案可以继续使用。
2. 在「QQ 账号」新增账号，填写该账号独立的 OneBot WebSocket 地址与连接密钥，选择默认人格。每个账号需要独立、已经登录的 NapCat / OneBot 实例；增加记录不会自动登录多个 QQ。
3. 在「群聊 / 私聊人格」选择账号、会话类型、群号或对方 QQ，再选择人格。绑定键是账号 + 会话类型 + 对方标识，同一键只能有一条记录。
4. 群绑定的「启用」同时开放该账号在这个群中的 @ 回复。默认账号还兼容旧群规则；旧规则已明确关闭的群与监测禁言群仍拒绝回复。额外账号需要自己的群绑定，默认账号的旧群名单不会自动授权给它。人格不授予主人私人资源权限。

## 数据与路由

```text
OneBot 账号 → 群聊/私聊绑定 → 人格 → 模型与会话记忆 → 同账号回复
```

会话绑定优先于账号默认人格；旧群组的 `profileId` 保留用于兼容旧方案。临时对话和长期记忆使用账号、人格与会话范围隔离，避免第二账号或另一人格读到前一会话的上下文。账号级全局记忆可在该账号内共享，请勿放入不应跨会话共享的私人资料；旧无账号范围的记忆仅按默认账号兼容规则读取。

设置格式为 v3：`accounts` 存账号，`profiles` 存人格，`bindings` 存群聊/私聊绑定。升级旧 v2 设置时保留旧数据、增加默认账号与空绑定，并先保留 `data/settings.v2.backup.json`；不要手动覆盖运行中的设置文件。密钥仍存加密凭据文件，不在设置界面回显。

## 两种通知与账号

实时重要提醒可以选择账号，只处理该账号在线收到的文字，默认等待 10 秒合并；不依赖 QCE。定时历史整理仍使用默认账号与 QQ Chat Exporter，报告持久保存。两者独立启用，不能把实时提醒当作离线消息补抓。
