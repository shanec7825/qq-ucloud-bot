# QQ Agent 2.4.0

- 六个入口：chat、语音、GitHub、云盘、ucloud、To Do。主任务优先，连接、筛选与高级设置按需展开。
- chat 按聊天对象选择普通或记忆模式，所有登录 QQ 共用模型、语音、工具及联系人规则。普通模式仅用人格与当前消息；记忆模式自动提取稳定自述，以账号、角色、联系人或群发言者隔离保存，带原文来源，可一键清空。旧手写记忆文件保留，但不再自动注入。
- 文字先发，语音生成后逐条补发；一轮最多八条消息。语音使用统一声音指令，兼容迁移旧音色描述，允许聊天模型微调本条表达。
- To Do 按群保存即时通知，单条加入待办。定时整理只保存本地；支持模板、格式和原文依据。日历生成 Google Calendar 草稿及 ICS，明确选择时间后由用户保存。
- GitHub / Drive 主卡片使用 ChatGPT Apps，检测区分登录、工具可见和实际读取。其他授权方式保留在二级设置。
- 推荐在线表情一键启用，下载后成为所有聊天共用的本地素材；QQ 内收藏仍保持会话范围。
- ucloud 凭据缺失时直接引导重新连接，不展示内部路径或 npm 命令。
- 支持原五插件向六插件升级；新增语音插件保留原有敏感词检查，拒绝未知插件信任项。
- MiMo 日常请求显式关闭额外推理；识别不完整响应，避免半截 JSON 进入业务流程。旧角色模型不会覆盖到不兼容的 MiMo 模型字段。

安装包和插件包不含个人设置、登录凭据或聊天数据。真实账户连接与当前运行目录的更新需要单独验证；构建成功不代表实网业务已经通过。
