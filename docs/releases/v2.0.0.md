# 2.0.0 本地候选版

**Last Updated:** 2026-10-21

本版本推送 main 后由 GitHub Actions 构建并发布。是否已经提供下载以发行页和流水线结果为准；源码推送不会自动替换正在运行的应用，也不代表完成真实服务写入验收。

## 变化

- 设置 v3 引入独立 OneBot 账号、人格池、群聊/私聊绑定和按账号/人格隔离的会话记忆。旧 v2 设置迁移前保留备份。见 [账号与人格](../ACCOUNT-PERSONAS.md)。
- 五个插件继续使用 NapCat 原生配置面板；核心增加账号、人格与绑定分类，通知增加实时提醒分类。见 [界面验证](../NAPCAT-NATIVE-UI.md)。
- 实时重要提醒选择账号、默认合并 10 秒，只分析在线收到的文字，无需 QCE；定时历史整理仍由默认账号读取 QCE 历史并保存报告。
- 主人私聊可选工具代理，默认关闭；写入默认关闭。默认最多 4 步，可设 1–8。写操作先展示具体内容，再由主人在同一 QQ 私聊使用一次性确认码确认，5 分钟有效；账号、人格、配置或授权变化会使确认失效。
- 工具结果可在同账号、人格及主人私聊范围内用于追问，最多保留最近 4 份、15 分钟，配置或授权变化后失效。
- GitHub 独立 REST 连接支持 Token 或已有 gh 登录：读取仓库、文件、提交、Issue、PR、分支和评审；受确认保护的操作包括文件更新、Issue 与 PR 创建/更新。ChatGPT 插件从实际工具目录及输入 schema 动态发现只读能力，不保证完整 REST 能力。
- Drive OAuth 区分只读与显式读写授权；独立连接的文件访问检查配置根目录。文本读取最多 32KB；Google 文档和 PDF 的可读文本还可经 ChatGPT 只读插件取得。独立写入包括创建/更新文本、移动和移入回收站，均需授权及确认。
- UCloud 根据当前公开前端 JS 适配个人文字作业，最多 2000 字符。预览 → QQ 确认 → 单次 POST → 回读核对；不支持附件或小组提交。结果不明时不自动重试，应先到教学云核对。
- 消息解析支持嵌套转发，最多深度 4、40 个节点、10 次补取 API；最多分析 3 张图片，GIF 使用首帧。表情包目录按会话范围隔离，使用 `/表情包` 列表和 ID 选择。QQ 输出采用纯文本格式并保留代码内容。

## 验证范围

149 项自动化测试通过，原版 NapCat 前端的 5 个插件及 8 次设置保存通过隔离验证。测试替身不能证明真实 QQ 收发、Google/GitHub 授权写入或学校作业已提交。本次未执行真实学校提交、Drive/GitHub 写入，也未替换正在运行的应用。8 个本地发行文件的 SHA-256 校验通过。
