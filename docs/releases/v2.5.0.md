# Qlyra 2.5.0

软件正式更名为 Qlyra，使用紫色折带 L 图标。Windows 窗口、托盘、安装向导、快捷方式及设置页使用统一名称与图标。保留旧安装标识、数据位置和 QQAgent.exe 兼容入口，升级时继续使用原配置。

语音新增 MiMo 音频复刻模式，与预置音色、文字设计音色并列。上传 WAV 或 MP3 参考音频后保存，即可使用 `mimo-v2.5-tts-voiceclone` 合成。Base64 上限 10 MiB，原文件约 7.5 MiB。音频存储于本机 `data/speech-references/`，设置只保存引用标识；合成时参考音频通过 MiMo 官方 `audio.voice` 参数发送。

固定参考音色可以配合每条对话的语气、情绪、语速、停顿及重音指导，保持声音身份。设置页支持原声回放、更换参考音频、带上一句对话的试听，以及手动指定本次试听表达。音色方式明确选择，修改表达要求不会自动切换模型。

语音页面分为“声音设置”和“试听”：设置页只显示当前音色模式所需内容，固定表达要求及连接参数按需展开；试听页只处理文本、播放与本次语气，模拟对话和实际表达指导默认收起。保存设置与生成试听分开操作。

使用步骤：打开语音设置，选择“上传音频复刻”，上传参考音频，设置固定表达要求，开启语音及聊天表达微调，保存后生成试听。仅使用有权使用的声音。

接口依据：[MiMo 官方语音合成文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。服务地址仍须与 MiMo Key 类型匹配；实际服务权限由所用账号决定。

本地自动化覆盖不代表已验证真实声音相似度或 QQ 实际播放。真实效果需上传本人选择的参考音频，在已授权账号下试听后确认。
