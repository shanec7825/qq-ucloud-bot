# Qlyra 2.6.1 for Windows

本版将首条回复提速与连续消息处理打入完整 Windows 发行包，包含 2.6.0 的回复协议 V2、文字与语音独立组织、图片回执核对及现有 Qlyra 设置页。

- 会话空闲时立即处理第一条消息；模型首个完整文字项通过校验后提前发送，图片与语音继续按完整计划准备和投递。
- 同一人的连续补充在尚未发送时取消旧生成，合并原问题与补充统一回答。待处理补充使用 300ms 收拢窗口，单批最多等待 1200ms，最多八条、合计 6000 字。
- 已发送的内容保留，旧回复尚未发出的气泡和语音停止；在途 QQ 发送先等待回执，避免重复投递或串话。
- 同群不同成员分别排队，账号、群与私聊会话隔离；斜杠命令独立处理，工具执行期间不因聊天补充而重跑动作。群内补充仍需要 @ 机器人。
- 群成员名单刷新最多等待 150ms，较慢时先使用已有成员与当前消息信息；作业、记忆、历史摘要与素材列表并行读取。
- 流式解析保留 UTF-8 与 SSE 分片边界，只使用正文增量，不发送推理内容、半句话、原始 JSON 或工具标签。损坏的后续计划停止投递，不重发首条文字。
- 桌面程序、后端和六个插件统一为 2.6.1；发行审计逐文件比较后端与源码，检查新消息模块已包含，并排除仅限开发机使用的补丁脚本。旧版配置与加密授权继续保留。

包含安装包 `Qlyra-Setup-2.6.1-x64.exe`、便携包 `Qlyra-2.6.1-win-x64.zip`、整套插件包 `Qlyra-Plugins-2.6.1-win-x64.zip`、六个独立插件包及 SHA-256 清单。`QQAgent.exe` 兼容入口继续保留。

一次真实 MiMo `mimo-v2.6-pro` 请求中，首条完整文字在 3143ms 进入本地接收器，完整生成在 8266ms 结束，提前 5123ms；这是单次模型链路观测，不能视为手机端延迟或长期平均。消息优化的全量本地回归共 361 项通过。QQ 实际投递与手机播放需在恢复 QQ 登录后确认。
