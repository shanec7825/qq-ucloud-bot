QQ Agent 首个 Windows 桌面发行版。

- 提供 QQ 登录、切换账号、插件设置、运行状态和后台控制的固定入口。
- 关闭窗口收起到托盘；可从桌面、开始菜单或托盘重新打开。
- 可以继续使用已有项目目录，不清空模型、提示词、群规则和其他服务授权。
- 保留机器人核心、GitHub、Google Drive、UCloud、群通知整理模块。
- 安装包内含 Node 24 LTS 和 WebView2 SDK；首次准备组件从官方源下载并校验 NapCat / Codex。
- 发行包不包含个人账号、会话、聊天历史或云盘凭据。

下载 `QQ-Agent-Setup-1.0.0-x64.exe` 安装，或完整解压便携 ZIP 后运行 `QQ-Agent/QQAgent.exe`。

需要 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。当前应用未做发布者代码签名。详见 README 和 README.Windows.md。

验证：84 项自动化测试通过；本机实际 WebView2 管理页、QQ 登录导航、托盘恢复和干净工作区初始化通过。没有为测试切换真实 QQ、发消息或调用模型。GitHub 发行资产由干净的 Windows runner 重建并附带 SHA256 校验与发行审核结果。
