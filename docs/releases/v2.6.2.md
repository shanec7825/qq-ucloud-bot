# Qlyra 2.6.2 for Windows

本版将 UCloud 作业访问权限纳入桌面完整发行包，并提供单独启动网页端的入口。桌面窗口与浏览器共用同一工作区、NapCat 后台、QQ 登录和设置，可以同时打开。

- UCloud 作业仅主人 QQ 私聊和 UCloud 设置中选择的群可查。支持群列表多选；未选择群时仅主人私聊可查。群聊回复规则与作业访问权限分别设置。
- 权限同时覆盖 `/作业`、`/详情` 和自然语言查询。未授权会话的普通聊天不读取或附带学校作业列表，权限变化后阻止旧请求继续返回作业内容。
- 安装后从开始菜单打开“Qlyra 网页版”，或在便携目录双击 `Qlyra-Web.cmd`。也可执行 `Qlyra.exe --web`：启动或复用本机后台、在默认浏览器打开网页，随后退出启动器，不保留桌面窗口或托盘。
- 桌面与网页端可同时使用。关闭任一界面保留后台；停止 AI 后台会让两种界面对应的机器人一起暂停。日常聊天和共享教材继续按原有规则使用。
- 保留 `QQAgent.exe` 兼容入口、原工作区、QQ 登录和加密授权。

发行文件包含 Windows x64 安装包、完整便携包、六个独立 NapCat 插件包、插件合集及 SHA-256 清单。真实 QQ 消息发送和手机端播放需要单独验收。
