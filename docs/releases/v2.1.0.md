# QQ Agent 2.1.0

- 一次模型回复可生成 1–4 条 QQ 消息，依次发送文字、图片、表情包和原生语音。同一会话整轮发送完后才处理下一条请求；群内只在首条引用和 @。
- 中途发送失败、群权限撤销或配置改变时停止后续消息。记录只包含已发送内容，避免把未发出的消息当成已送达。
- 新增持久图片与表情包素材库，可在扩展页上传、预览、删除，也可在 QQ 附图或引用图片收藏。素材按账号和会话隔离，保留 GIF 原文件。
- 接入小米 MiMo / Token Plan TTS，发送 QQ 原生语音条；支持预置音色、文字设计音色、固定风格和逐条语调/情绪/语速/停顿指导。普通语音回复在同一次模型请求中生成正文与表达指导。
- 同轮多条语音各自合成、按顺序发送，共用一次频控名额；失败保留文字并停止多余 TTS 请求。
- 整合 DeepSeek API 与官方 Harness 接入、独立密钥、角色模型路由，以及现有工作区的分类设置、联系人选择和教学云查看入口。
- 完善模型进程隔离与完成事件处理；升级时保留账号、授权、角色和素材。发行包包含项目许可证与新增功能说明，不包含本机数据和凭据。

本地隔离测试覆盖分条顺序、并发队列、权限变化、发送失败、TTS 批次、媒体隔离和配置页面。真实对话模型已验证可生成独立语音指导；小米合成、QQ 语音转换和设备播放仍需使用有效 Key 进行实际验收。
