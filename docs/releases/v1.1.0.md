QQ Agent 1.1.0：插件下载、群场景模板与单侧边栏桌面界面。

- 发布机器人核心、GitHub、Google Drive、UCloud、群通知整理五个独立插件 ZIP，以及整套 Windows x64 插件包。核心携带干净后端和 Node，模块共享配置；无开发者本机路径、账号或凭据。
- 每群默认由 AI 在同一次回答中选择游戏/年级/课程场景；可固定模板、查看示例、设置每群补充要求。闲聊不套表格，不为选择模板增加模型请求。
- 桌面原有一列按钮并入 HTML 侧边栏；进入 NapCat 后沿用 NapCat 导航，顶部工作台可返回。
- 保留显式 @ 触发、监测群禁言、私人连接器权限与现有数据。

使用 Windows 安装包，或按 README 下载独立插件。独立插件依赖已有 NapCat 和 OneBot 配置；部分构建有第三方插件白名单限制，GitHub 发布不代表已收录官方市场。ChatGPT 订阅需自己的 Codex 登录，API 需自己的密钥。

发行包附带 SHA256SUMS、发行审计和插件审计。测试包含旧群配置兼容、模板按群隔离、单请求模板选择、设置持久化、插件异地初始化与升级数据保留；未发送真实 QQ 消息或调用模型。
