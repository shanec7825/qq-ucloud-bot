# QQ Agent 2.3.0

- 启动向导新增「连接与端口」：展示本机端口监听情况（NapCat 面板 6099、OneBot 连接 3001、管理接口 6100 为必需），标出配置中仍启用的多余入站端口与被其它工作区占用的端口；一键「关闭多余端口」把 OneBot 入站收紧到本机回环上的必需连接（需要时自动重启后台生效），一键「关闭其它后台」退出占用端口的其它工作区 NapCat 并释放端口。非 QQ Agent 的程序一律不结束，只列明路径请手动处理。
- 端口被其它工作区占用时，工作区卡片直接给出原因、被占端口与对方进程路径，并提供「关闭其它后台并继续」，不再需要手动查找退出。
- 运行时组件按模型提供方展示：NapCat（必需）之外，ChatGPT / Codex 认证组件与小米 MiMo / Token Plan 组件并列，二选一的模型提供方各自显示就绪状态；MiMo / Token Plan 行显示 Key 类型与后端、语音地址是否匹配（不显示 Key 本身），并可一键进入配置。
- 取消确认框的操作也会正确收尾，界面不会停留在忙碌状态。

本地验证：219 项自动化测试全部通过（含端口冲突、端口收紧、Key 脱敏等新场景）；启动向导在 375 / 1440 宽度与浅色 / 深色主题下通过界面检查；桌面程序以 .NET Framework 编译器编译通过，发行包与插件包通过内容审核。
