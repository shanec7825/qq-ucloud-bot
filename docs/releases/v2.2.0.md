# QQ Agent 2.2.0

- 桌面启动页重做为启动向导：集中完成系统环境检查（Windows 10/11 x64、.NET Framework 4.8、WebView2、Node 运行时、PowerShell）、工作区目录设置与运行时组件准备，首次使用按向导即可跑通；系统组件缺失会给出修复指引，WebView2 缺失直接提供官方下载入口。
- 新增「一键准备并启动」：自动下载并校验 NapCat / Codex 运行组件、写入本机配置、拉起后台并进入 NapCat WebUI。下载、解压、配置、启动各阶段进度实时显示在启动页，任务栏托盘「运行管理」提供同一入口；也可继续分步使用「准备运行组件」与「启动机器人」。
- 启动页与扩展设置页共用同一套前端组件与主题（HeroUI 风格），支持浅色 / 深色与窄窗口布局；发行包带上全部启动页资源，QQ 状态、机器人连接、所选模型、组件版本和失败原因都直接显示在对应分区。
- 回答模型新增 MiMo API（按量计费）与 MiMo Token Plan（中国集群）；MiMo / Token Plan Key 共用一个密钥位，配置页按所选后端只显示相关凭据。语音配置的集群地址改为可读名称（MiMo Token Plan 中国 / 新加坡 / 欧洲集群、MiMo API），表达指导统一为 MiMo TTS 指导并保留已选音色。
- 文档更新首次打开流程，补充网页与后台启停说明；升级保留工作区中的账号、授权、角色、记忆与素材。

本地验证：210 项自动化测试全部通过；启动页在 375 / 1440 宽度与浅色 / 深色主题下通过界面检查（含进度忙碌态、一键链路与错误反馈）；桌面程序以 .NET Framework 编译器编译通过，发行包通过内容审核。真实 QQ 登录、模型请求与语音合成仍需使用实际账号验收。
