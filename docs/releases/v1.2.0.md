# 1.2.0 — 统一工作台与可复用机器人方案

本地开发版；未发布到 GitHub。

## 行为变化

- 桌面入口、独立管理页面和 NapCat 内嵌设置使用统一视觉与组件规范。
- 自定义机器人方案可在多个群中复用，群选择方案后使用对应名字、提示词和可选模型覆盖；模型后端与权限仍由全局配置决定。
- 长期记忆支持分类、标签、启停和方案范围；保留群、私聊及全局隔离。
- 历史自动摘要与手工修订分离，后台任务不会覆盖手工内容。
- 消息收件箱可标记完成、归档和恢复待处理；原文依据保持不变。
- 配置版本升级至 2，保留旧身份、模型、群设置与 revision 并发检查。

## 升级与恢复

升级前在本机备份工作区 `data/` 和 `.env`，备份含私人信息，不要上传。新版首次加载配置时迁移旧格式，并以独占创建方式保留 `settings.v1.backup.json`。回退到旧版时应一并恢复升级前配置；不要把旧程序直接指向新版配置。安装包、便携版和插件包不包含个人工作区数据。

多个机器人方案共用一个 QQ 连接。真正的同时多账号、向量数据库和第三方动态插件运行不包含在这个版本内。架构依据和下一阶段边界见 [工作台架构](../WORKSPACE-ARCHITECTURE.md)。

## 验证记录

- Node 25 开发环境与发行包 Node 24.22.0：全部 100 项自动化测试通过。
- Edge 隔离浏览器：机器人方案创建、群绑定、保存刷新、删除保护、记忆分类/范围/启停、摘要草稿、消息事项完成/归档/恢复和原文依据通过。
- 六个管理页面、五个模拟 NapCat 模块及桌面首页：375px / 1440px、浅色 / 深色布局通过，真实 iframe 的宿主主题切换通过。
- C# 桌面宿主使用 .NET Framework 编译器与 WebView2 引用编译成功；JavaScript 和 C# 专项审查发现的问题已修复。

运行 `npm test`、`npm run test:ui`、`npm run test:workspace-ui` 可分别复查后端、原有管理流程和新工作台流程。Windows 沙箱可能限制 localhost 或临时目录操作，验证时使用隔离的工作区临时目录。

本地自动化使用隔离数据与假连接，不代表已经验证真实 QQ、学校、云盘或模型服务。界面截图中的账号连接状态是测试夹具，不是实时账号状态。此版本尚未安装到当前运行中的应用，也未发布到 GitHub；新包从本地发行目录使用。
