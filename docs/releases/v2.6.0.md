# Qlyra 2.6.0

新版回复协议 V2 将文字、图片、说话与唱歌拆成明确类型。应用版本为 2.6.0，消息协议版本为 2。

聊天 Agent 仅声明发送内容；宿主在整轮校验通过后选择当前账号、会话、已授权素材、语音服务和投递路径。文字项不会隐式朗读，唱歌使用 speech.mode=sing，由宿主临时选择 MiMo 预置 TTS 并加上唱歌标签，日常复刻音色设置保留。

MiMo 请求启用官方 JSON 模式；ChatGPT / Codex 请求使用随包提供的 JSON Schema。两者均执行本地字段、权限、素材、长度和数量校验。格式异常最多重新生成一次，发生投递错误后不重新生成整轮、不盲目重发图片。旧格式保留有界解码兼容。

包含 2.5.1 的语音去重、图片超时回执核对及技术错误只记本机日志的改进。详细设计、来源与证据边界见 docs/REPLY-PROTOCOL-V2.md。
