QQ Agent Windows 桌面版 1.0.1。

包含 QQ 登录、切换账号、插件设置、后台控制与托盘恢复入口。修复首页频繁刷新触发 NapCat 登录限流、在线 QQ 偶尔误显示为服务未启动的问题：本机管理会话通过 Windows DPAPI 加密复用，失效或重启后自动重新认证。

下载 QQ-Agent-Setup-1.0.1-x64.exe 安装，或完整解压便携 ZIP 运行 QQ-Agent/QQAgent.exe。Windows 10/11 x64，需要 .NET Framework 4.8 和 WebView2 Runtime；当前未做发布者代码签名。发行包不含个人配置、QQ 缓存或授权信息。

验证：85 项自动化测试；本机实际管理页面、QQ 登录导航、托盘恢复、停止/启动、连续状态刷新验证通过。测试未切换 QQ、发送消息或调用模型。安装和使用说明见 README。
