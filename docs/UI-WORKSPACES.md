# UI 工作台

此文记录 2.3.0 的界面。2.4.0 当前结构与业务边界见 [PRODUCT-WORKSPACES.md](PRODUCT-WORKSPACES.md)。

**Last Updated:** 2026-10-22

启动页使用粉色渐变、彩色光晕与轻量动态效果，跟随深浅主题和系统减少动态效果设置。进入 NapCat 后，原生插件卡片保留简版设置；扩展页面提供图标分组导航、列表与编辑区。模块切换保持在 NapCat 扩展页内，窄屏使用横向滚动导航。

## 角色与管理

“角色”同时管理默认全局角色和自定义角色。未指定角色时使用默认全局角色；群聊、账号和会话仍可分配自定义角色。“管理与权限”负责管理员 QQ，角色名称和系统提示词在角色编辑区设置。

## 教学云

独立入口为“待交作业”“站内通知”“连接与提醒”。作业可搜索并阅读详情；通知可搜索当前页、翻页及阅读正文，阅读不会自动标记已读。首次使用先保存连接设置，连接失败时可重试。窄屏可在列表与正文间返回。

## 群消息

两种工作流都按“来源 → 筛选／整理 → 推送”排列：

| 工作流 | 来源 | 处理与输出 |
| --- | --- | --- |
| 即时通知 | 所选 QQ 与群 | 包含关键词命中任一；排除词优先；可限制发送人 QQ、最低重要级别及关注事项；支持简洁／详细输出。 |
| 历史整理 | 默认 QQ 与群 | 可跟随群场景，或选择通用、课程、工作、自定义模板；可补充整理要求；支持简洁／详细输出。 |

“推送预览”是本地格式示例，切换模板与格式即可查看排版，不调用模型或发送消息；实际内容以来源消息和整理结果为准。即时通知与历史整理分别启用、保存和选择接收人。

## 兼容性与验证

现有账号、角色、群组分配和记忆继续沿用；扩展工作台与原生简版设置操作同一份配置。多 QQ 仍需每个账号独立运行 OneBot / NapCat 实例。设置接口继续校验配置版本，密钥不回显，留空保留原值。

本轮已通过 227 项 Node 测试、五个模块的 NapCat 原生 UI 验证、启动页 375 / 1440 像素双主题验证，以及五模块完整扩展页回归（20 次保存）。扩展页覆盖角色合并、通知筛选与模板、教学云阅读、顶部模块连续切换、页内确认、深色与窄屏，以及模型、素材和语音页面。隔离 UI 测试使用本地测试数据，不证明真实 QQ 推送、模型调用或教学云授权已经连通。
