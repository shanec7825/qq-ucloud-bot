# 工作台与业务边界

更新：2026-10-23，2.4.0。

## 页面结构

| 入口 | 首屏 | 二级设置 |
| --- | --- | --- |
| chat | 联系人普通／记忆模式、角色分配；会话统一查看对话、已学记忆、群摘要 | 回答模型、管理与权限、资料库、NapCat 连接 |
| 语音 | 单条声音指令、启用、自动微调、试听 | 服务地址、模型、长度限制、密钥 |
| GitHub / 云盘 | ChatGPT Apps 状态、选用、实际读取检测 | Token、本机已有授权、Google OAuth |
| ucloud | 待交作业、站内通知、正文 | 连接与提醒、学校认证 |
| To Do | 按群通知、显式加入的待办、本地整理 | 关注群、筛选、模板、输出格式、整理时间 |

启动页面沿用 NapCat 的粉色、彩色光晕与轻量动态，扩展页使用同套主题变量及图标。复杂选项折叠；主页面不显示上下文容量、机器人账号选择、推送级别或接收人。原生旧配置接口继续兼容，主导航不再展示长期记忆、历史读取与分散的摘要页面。

## 共享配置与隔离记忆

共享的是模型、语音、工具、联系人模式、群来源规则。多个登录 QQ 是连接通道，不是多份业务配置。联系人显式选择默认全局角色时，优先于旧连接的默认角色。

普通联系人不写入、检索、注入近期或长期会话；语音表达分析也不读历史。记忆联系人异步学习明确自述的稳定偏好和事实，先过滤敏感内容、引用、临时状态与指令，再调用当前模型提取；每条结果须能逐字对应来源。保存原文证据、观察时间与置信度，以主题键更新并去重，不落盘整个学习原始聊天。

学习范围为 `account:<id>:profile:<id>:private:<peer>`；群内再包含 `group:<id>:sender:<id>`。知识、近期聊天、人格和来源分开，回答时按当前问题检索。每范围最多40条，提取并发最多2，召回最多8条和1600字，这些是内部策略，不暴露为用户参数。旧 `memory-notes.json` 保留备查，不再自动注入。

参考了 [Mem0 的提取、标识符范围及相关性检索](https://docs.mem0.ai/core-concepts/memory-operations/add)，以及 [OpenClaw 的持久记忆与会话上下文分离](https://docs.openclaw.ai/concepts/memory)。本项目采用本地 JSON 与现有模型实现这些流程，没有宣称集成其云服务或向量数据库。当前学习偏保守，仅明确自述可入库；不推断隐含个人信息。

清空联系人会取消在途学习，删除已学记忆与近期私聊，清理工具及 Drive 选择缓存，并使旧工具作用域和回复失效，防止异步回填。

## 回复与网络

文字、图片先按回复计划发送，再开始语音合成；每段音频就绪即发送。总计最多八条、6000字文字、4000字语音、两张图片、18个发送段。TTS 默认串行，允许有界并发，不自动重试已可能扣费的合成。

复用 Node 原生 fetch 的连接池，不改变系统代理、VPN或现有路由。MiMo 日常调用明确发送 `thinking.disabled`，见[官方深度思考参数](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/other/deep-thinking)，并检查截断／过滤响应。是否更快仍应通过相同网络下的真实请求比较，不以构建或单元测试推断。

Token Plan 端点能返回内容，不等于任意后台用途均在套餐适用范围；部署前应核对[官方 Token Plan 说明](https://mimo.mi.com/docs/zh-CN/tokenplan)。不伪造客户端或自动切换计费服务。

## 通知与日历

即时消息仅处理选中群，空列表表示没有来源；跨连接按群、消息编号去重，每群独立识别和保存。配置变更取消旧结果。没有自动 QQ 私聊推送。定时整理仍使用现有本地导出服务，不再私聊发送。

通知和整理不是自动待办；点击加入后才进入待办，待办独立持久保存，不因来源过期而消失。简洁格式折叠依据，详细格式默认展开。Google Calendar 使用草稿链接，ICS 使用同源宿主下载适配以兼容 NapCat iframe；不自动创建远端事件，不推断相对日期。

## 工具和素材

GitHub / Drive 通过已有 Codex App Server 的只读工具连接；登录状态不当作成功读取。主卡片可切换授权方式并验证实际读取，失败时保留明确状态；需要用户在 ChatGPT / Codex 中连接对应应用。可用性还依赖本机 Codex 组件和账号授权。

推荐图库使用 [Memegen 官方 URL 规范](https://memegen.link/guide/)中的固定公共模板。不会将聊天内容或搜索词放入外部 URL；下载禁止重定向，限制体积并验证图片，保留素材来源。启用后缓存本地并跨登录 QQ 使用，不自动抓取任意网页。真实外网下载的可用性须另行验证。
